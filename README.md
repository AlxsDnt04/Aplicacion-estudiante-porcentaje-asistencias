# Aplicación Estudiante - Porcentaje de Asistencias

Esta es una aplicación web diseñada para calcular y gestionar el porcentaje de asistencias de estudiantes. Es ideal para profesores, instituciones educativas o cualquier persona que necesite llevar un registro de asistencia de estudiantes de manera eficiente.

## Características

- **Registro de asistencia:** Permite registrar las asistencias de los estudiantes.
- **Cálculo automático:** Calcula el porcentaje de asistencia de cada estudiante.
- **Interfaz amigable:** Diseño atractivo y fácil de usar.
- **Tecnologías utilizadas:**
  - **HTML:** Para la estructura de la aplicación.
  - **CSS:** Para el diseño y estilo.
  - **JavaScript:** Para la lógica y funcionalidad.

## Requisitos del sistema

- Navegador web actualizado (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.)
- [Node.js](https://nodejs.org/) (opcional, si deseas realizar pruebas o personalizar la aplicación)

## Instalación y uso

1. Clona este repositorio:
   ```bash
   git clone https://github.com/AlxsDnt04/Aplicacion-estudiante-porcentaje-asistencias.git
   ```

2. Accede a la carpeta del proyecto:
   ```bash
   cd Aplicacion-estudiante-porcentaje-asistencias
   ```

3. Abre el archivo `index.html` en tu navegador para ejecutar la aplicación.

## Estructura del proyecto

- **`index.html`**: Archivo principal de la aplicación.
- **`styles.css`**: Archivo de estilos para el diseño de la aplicación.
- **`script.js`**: Archivo JavaScript que contiene la lógica de la aplicación.
